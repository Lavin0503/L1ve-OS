## ⬇ Download

**The `.exe` is not stored in the repository files. To get it, go to the [Releases page](https://github.com/Lavin0503/L1ve-OS/releases) and download `L1veOS.exe` from the latest release.**

Direct link to v1.0.0: [L1veOS.exe](https://github.com/Lavin0503/L1ve-OS/releases/download/v1.0.0/L1veOS.exe)

1. Open the [**Releases**](https://github.com/Lavin0503/L1ve-OS/releases) tab on the right side of this page.
2. Under the latest version, open **Assets**.
3. Click **`L1veOS.exe`** to download it.
4. Run it and follow the installer.

> **Windows SmartScreen:** because the app is new and unsigned, Windows may show a "protected your PC" warning. Choose **More info → Run anyway** if you downloaded it from this repository's Releases page.

## ✨ Features

- **Draggable desktop icons** that snap to a grid and remember their position
- **File manager** with folders, search, cut/copy/paste, rename, drag and drop, and file properties
- **Recycle Bin** with restore, delete forever, and empty
- **Taskbar** with pinned apps, folders and files, reorderable by dragging
- **Start menu**, right-click menus, and snap-to-edge windows
- **L1VE Store** with free apps: Snake, Tic-Tac-Toe, Memory Match, Piano, Focus Timer, Sticky Notes and more
- **Built-in apps:** Notes, Terminal, Calculator, Paint, Browser, Task Manager, To-Do, Calendar, Clock, Settings
- **Personalization:** dark and light themes, accent colours, wallpapers, PIN sign-in, reduce motion

## 💾 Your data

Files and settings are saved locally on your device, so your desktop is how you left it. The **Settings → Reset** option erases it.
